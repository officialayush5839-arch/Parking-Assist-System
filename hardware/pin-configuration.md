# Pin Configuration

## Arduino Uno Pin Mapping

| Component | Pin Function | Arduino Pin | Notes |
|-----------|--------------|-------------|-------|
| HC-SR04 | VCC | 5V | Power |
| HC-SR04 | GND | GND | Ground |
| HC-SR04 | TRIG | D9 | Output |
| HC-SR04 | ECHO | D10 | Input |
| I2C LCD | VCC | 5V | Power |
| I2C LCD | GND | GND | Ground |
| I2C LCD | SDA | A4 | I2C Data |
| I2C LCD | SCL | A5 | I2C Clock |
| Green LED | Anode | D2 | Output, use 330 ohm resistor |
| Yellow LED| Anode | D3 | Output, use 330 ohm resistor |
| Red LED | Anode | D4 | Output, use 330 ohm resistor |
| Buzzer | Positive | D5 | PWM Output |
